# 0001:建立工作憲法與制度檔案

日期:2026-07-04
狀態:生效

## 情境

本 repo 的工作由不同能力等級的 AI session 輪流接手,session 之間沒有共同記憶。
沒有制度時,每個 session 的品質完全取決於當次模型的判斷力,且探索成果、決策、
踩過的坑全部隨 session 消失。2026-07-04 由一個高能力模型 session 一次性把
可長期沿用的判斷力寫成制度。

## 決定

建立四層制度:`CLAUDE.md`(憲法:鐵律 + 分級 + 路由,每 session 自動載入)、
`docs/playbooks/`(五份情境手冊,按需載入)、`STATE.md`(session 間交接檔)、
`docs/decisions/`(ADR)。修訂制度必須經 CLAUDE.md 第 6 節的程序。

## 理由與代價

寫給較弱模型的規則必須「觸發條件 + 動作 + 範例」三件俱全,抽象原則等於沒寫,
因此全部規則都以可數的判準(次數、行數、檔案數)與自檢問句表述。
代價:每個 session 多出固定的儀式成本(讀/寫 STATE.md、commit、push),
S 級純問答任務已豁免;若儀式成本在實務中仍過高,依修憲程序調整而非私下跳過。
